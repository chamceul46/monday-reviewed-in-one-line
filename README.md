Entry for the make.fun bounty [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1).

The review (101 of the allowed 200 characters):

> One star. My Monday started with 214 unread emails and ended with 216, and I answered emails all day.

It is written to the brief the judge scores: it reads as a review from the first two words, the detail is concrete — an inbox, counted — rather than generic tiredness, and the joke is arithmetic: a full day of answering email and the unread count went *up* by two. No wasted words, the turn lands inside the line, and it is exactly the sentence a coworker repeats the next morning.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
```

`main.py` validates the line against the bounty gate (UTF-8 text of 1 to 200 characters, not only white space) before writing it to `entry.txt` in the output directory (`/output` by default, as in the grader).
